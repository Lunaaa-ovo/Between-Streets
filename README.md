# 漫游之间 · Between Streets

一个温暖手账风格的个人网页，记录代码、厨房和镜头里的生活。

## 本地预览

双击 `index.html`，或在项目目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000`。

无需构建或安装前端依赖。所有字体、插画及角色资源均保存在本地。

## 功能

- 鼠标水平移动控制角色转向，手机点击切换方向。
- 项目详情弹窗、相册预览、导航定位与键盘交互。
- 响应式布局、加载失败静态回退与减少动态效果支持。

## 编辑内容

`index.html` 保存介绍、项目、美食和照片入口；`css/pixel.css` 保存样式；`js/pixel.js` 保存交互与弹窗内容。

美食与部分项目仍为待填写内容；相册目前使用示意插画。角色与部分装饰素材由AI辅助生成，个人照片仅用于本网站展示。

## 文件与隐私

此仓库仅包含网页运行文件，不含任何生成服务密钥、凭据工具、原始视频、运行日志或开发备份。网页无需调用付费生成接口。

思源黑体 / Noto Sans SC 字体的授权见 `assets/fonts/OFL-NotoSansSC.txt`。个人照片不作为开源素材授权。
