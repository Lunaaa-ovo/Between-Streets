# 漫游之间 Between Streets

赵小瑄的奶油手账与像素风个人主页。包含个人介绍、代码项目、美食轮播和像素日常相册。

## 运行

解压后直接双击 `index.html`，使用 Chrome、Edge 等现代浏览器打开。也可在本目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。前端无需 Node.js、npm 或任何付费生成接口。

在线地址：[漫游之间](https://lunaaa-ovo.github.io/Between-Streets/)

## 文件

- `index.html`：网页结构与内容。
- `css/pixel.css`：视觉、响应式、主题与动效。
- `js/pixel.js`：角色、导航、轮播、弹窗与主题交互。
- `assets/`：本地图片、透明图集、贴纸、字体与授权文件。
- `motion-girl/source/front.png`：角色静态回退。

## 交互

鼠标左右移动控制人物转向；点击人物有回应。美食支持自动与手动切换、暂停、键盘和滑动。照片可打开大图。顶部按钮切换关灯主题并记住选择。Mini 贴纸可悬停放大、点击切换状态。手机端使用可展开的导航菜单，选择栏目后自动收起。

## 无障碍与资源

可用 Tab 遍历主要按钮，首个“跳到主要内容”链接可以跳过导航。菜单支持 Esc 关闭与焦点回到按钮。开启“减少动态效果”时角色显示静态图、轮播停止自动播放。图集失败时保留正面静态角色。

字体使用 Noto Sans SC，根据当前网页字符提取为 WOFF2 子集；许可见 `assets/fonts/OFL-NotoSansSC.txt`。新增不包含的字符会回退到系统字体；修改文案后可重新生成子集。原始字体、旧网页、生成日志和凭据均不属于运行所需文件。

素材包含 AI 辅助生成的角色、背景、贴纸和像素插画，相册插画不作为实拍照片展示。本项目使用 oil-motion 的制作流程与本地适配脚本，将已生成视频整理为鼠标控制的透明图集；网站访问时不调用生成服务。没有后端留言提交功能。
